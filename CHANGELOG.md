# Changelog

## 0.1.0a1

Initial public alpha of the standalone knowledge framework:

- Local SQLite vault, immutable sources, evidence, versioned cards and relations.
- Reviewable changesets, partial staging, atomic commit and inverse revert.
- FTS5 and optional rebuildable Chroma search; evidence-backed answers.
- OpenAI-compatible local/cloud providers with explicit transmission consent.
- CLI and chat-first Textual TUI; macOS native file access and DOCX import.
- Dialogue service/reasoning filtering and explicit AI-reply provenance.
- Independent packaging, locked development workspace and manual release gates.

This is an alpha release; see README for limitations before v1.
